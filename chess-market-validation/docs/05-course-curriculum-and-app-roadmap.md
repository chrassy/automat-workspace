# 05. Plan de Estudios (Curriculum) y Hoja de Ruta de Producto

## 1. El Curriculum del Curso: "Método JaquePro (800 a 1600 ELO)"

Diseñado con un enfoque 80/20: el 20% de los conceptos que producen el 80% de las victorias en partidas rápidas y estándar.

### Módulo 1: Eliminación de Errores Graves ("Cero Blunders")
* Lección 1.1: El mapa de casillas indefensas y visión periférica.
* Lección 1.2: El protocolo de 3 pasos antes de soltar la pieza.
* Lección 1.3: Detección instantánea de clavadas, horquillas (dobles) y ataques a la descubierta.
* *Práctica Interactiva:* 50 puzzles de detección de amenazas en 1 jugada.

### Módulo 2: Repertorio Compacto de Aperturas (Sin Memorizar Biblias)
* Lección 2.1: Los 4 principios universales de apertura que derrotan jugadas raras.
* Lección 2.2: Para Blancas: El Sistema Londres y Ataque Italiano Moderno.
* Lección 2.3: Para Negras contra 1.e4: La Defensa Francesa / Caro-Kann simplificada.
* Lección 2.4: Para Negras contra 1.d4: El esquema sólido de peón dama.
* *Práctica Interactiva:* Entrenador de variantes de los primeros 8 movimientos.

### Módulo 3: Planes de Medio Juego y Coordinación
* Lección 3.1: ¿Qué hacer cuando ya sacaste todas las piezas?
* Lección 3.2: Cómo crear y aprovechar una debilidad en el enroque enemigo.
* Lección 3.3: Rupturas de peones que abren líneas de ataque.
* Lección 3.4: El arte de simplificar cuando tienes ventaja de material.

### Módulo 4: Finales Esenciales que Ganan Partidas
* Lección 4.1: Finales de Peones: La regla del cuadrado y la oposición del rey.
* Lección 4.2: Finales de Torre básicos (posición de Lucena y Philidor explicadas en 5 minutos).
* Lección 4.3: La técnica para coronar sin permitir ahogados accidentales.

## 2. Producción Interna ("Do-It-Yourself" Tech Stack)

Podemos producir y entregar el 100% del producto nosotros mismos con coste mínimo:

| Componente | Herramienta / Tecnología | Coste |
| :--- | :--- | :--- |
| **Grabación y Edición de Clases** | OBS Studio + Micrófono USB + DaVinci Resolve (Gratis) | €0 |
| **Tablero Visual en Vídeos** | Tablero SVG interactivo / Lichess Board Studio | €0 |
| **Plataforma Web / App MVP** | FastAPI / Python + HTML5/CSS3/JS interactivo + SQLite/PostgreSQL | < €10/mes |
| **Motor de Ajedrez para Ejercicios** | Stockfish WebAssembly / Chess.js | €0 (Open Source) |
| **Procesador de Pagos** | Stripe Checkout / LemonSqueezy (con soporte para tarjeta y PayPal) | Comisión estándar ~2.9% |
| **Email Marketing y Automatización** | Resend / Brevo / MailerLite (Tier gratuito hasta 1,000-2,000 suscriptores) | €0 |
