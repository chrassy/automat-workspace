# iPhone 18 AERO-SHIELD Pro Case — Product Landing Page

Interactive, high-converting product showcase and pre-order platform for the next-generation **AERO-SHIELD Pro Case** designed for iPhone 18, iPhone 18 Pro, and iPhone 18 Ultra.

## Key Features

- **Interactive 3D / Multi-Angle Visualizer:** Real-time rendered case specimen with 4 angle views (Back Rim, Isometric 3D, Front Shield, X-Ray Graphene).
- **Live Armor Configurator:**
  - Dynamic model selection (iPhone 18 6.1", iPhone 18 Pro 6.3", iPhone 18 Ultra 6.9").
  - Aerospace Composite finishes (*Stealth Obsidian*, *Titanium Slate*, *Cosmic Amber*, *Cyber Cyan*, *Lunar Ceramic White*).
  - Tactical button accent selection (Raw Titanium, Electro Gold, Neon Orange, Cyber Blue, Ruby Crimson).
  - Live laser engraving preview on the case backplate (with character limit validation).
  - Bundle protection add-ons with automatic discount calculation (Dual Sapphire Lens Guard, 9H+ Privacy Shield, Tactical Paracord Lanyard).
- **25ft Drop Impact Physics Lab:**
  - Interactive height slider (3ft to 40ft) and surface selector (Concrete, Granite, Steel, Hardwood).
  - Impact velocity (MPH), peak G-force deceleration, and kinetic energy dissipation telemetry calculations.
- **MagSafe 3.0 Ultra-Flux Visualizer:**
  - Interactive magnetic accessory snap demonstration (Snap Wallet, Qi3 30W Cryo Powerbank, Car Vent Mount, Studio Desktop Stand).
- **Head-to-Head Comparison Benchmark Matrix:**
  - AERO-SHIELD Pro vs OEM Apple Silicone vs Bulky Heavy-Duty Armor vs Generic TPU.
- **Cart & Pre-Order Checkout System:**
  - Slide-over bag drawer with coupon code validation engine (`LAUNCH18`, `CREW20`, `VIPEARLY`, `FREESHIP`).
  - Multi-currency switcher (USD $, EUR €, GBP £, CAD $, JPY ¥).
  - Interactive checkout modal with instant confirmation, unique batch Order ID generation, and lifetime warranty registration token.
- **Order Tracking & Warranty Lookup:**
  - Real-time pre-order dispatch status and warranty lookup portal.
- **Community Reviews & Review Submission:**
  - Filterable verified customer review feed and interactive review submission.
- **FAQ Accordion & VIP Early Access Newsletter Subscription.**

## Tech Stack

- **Backend:** Node.js, Express.js
- **Frontend:** Responsive HTML5, Vanilla JavaScript, CSS3 Custom Properties (Dark glassmorphic aesthetic)
- **Testing:** Jest, Supertest, JSDOM

## Quick Start

```bash
# Install dependencies
npm install

# Run the server
npm start
# Visit http://localhost:3000

# Run full test suite
npm test
```
